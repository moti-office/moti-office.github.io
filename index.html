MOTI Office Backup

모티 회사 계정으로 사용하는 백업 연결 도구입니다. 회사 Google 계정과 앱 전용 Drive 폴더를 연결하고, 회사 자료의 암호화 백업과 격리 복구를 준비합니다.

주요 기능

  • 회사 계정과 저장공간, 전용 백업 폴더의 접근 권한 확인
  • 운영자가 별도로 활성화한 경우 암호화 자료 백업과 복구
  • 백업 상태와 오류 확인

Google Drive 접근 범위

앱에서 사용하도록 허용된 특정 파일에 적용되는 drive.file 권한을 사용합니다. 회사 계정의 앱 전용 백업 폴더를 대상으로 하며, 일반 Drive 전체 접근 권한을 요청하지 않습니다.

현재 상태

연결 준비 단계입니다. 실제 자료 업로드와 자동백업은 아직 활성화하지 않았습니다. Google 연결 동의만으로 백업이나 모티 작품 제작을 시작하지 않습니다.
