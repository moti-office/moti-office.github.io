처리하는 정보와 목적

  • Google 계정 이메일: 회사 계정 일치 확인
  • 저장공간 사용량·한도: 백업 가능 용량 확인
  • 앱 전용 폴더·파일의 식별자, 권한 및 검증 정보: 백업 위치 확인과 무결성 검증
  • OAuth 인증정보: 동의한 범위의 연결 유지와 인증 갱신
  • 운영자가 백업을 별도 활성화한 경우의 암호화 자료: 회사 자료 보관과 복구

접근과 이용 제한

drive.file 권한으로 앱이 사용하도록 허용된 특정 파일에 접근합니다. 백업 연결을 위해 얻은 Google 데이터와 인증정보는 연결·백업·복구 목적으로 사용하며, 광고나 AI 모델 학습에 사용하지 않습니다. Google API Services User Data Policy에 맞춰 처리합니다.

보관과 접근

인증정보는 운영자가 관리하는 접근 제한 저장소에 보관하며, 공개 코드 저장소나 안내 페이지에 포함하지 않습니다. 백업을 활성화할 경우 자료는 암호화해 지정된 회사 Drive 폴더에 보관합니다. 복구용 비밀키의 별도 보관과 서버 배치는 운영 전 준비 사항입니다.

현재는 연결 준비 단계이며 실제 백업 자료 업로드와 자동백업은 꺼져 있습니다.

연결 해제와 삭제 요청

Google 계정의 서드 파티 연결 관리에서 권한을 취소할 수 있습니다. 권한 취소는 이후 접근을 중지하며, 이미 보관된 백업을 자동 삭제하지는 않습니다. 인증정보 또는 백업의 삭제·보관 관련 요청은 관리 담당자에게 보내주세요. 기존 승인·원장 보존 범위를 함께 확인해 처리하며, 현재 자동 삭제 기능은 활성화하지 않았습니다.
